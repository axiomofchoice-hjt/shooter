# shooter

一个用 React + Vite + TypeScript 制作的 2D 俯视角地牢射击游戏原型，桌面和手机双端适配，地牢房间为直线排布的 roguelike 楼层。

## 启动

```bash
npm install
npm run dev
```

打开终端里显示的地址（默认 `http://localhost:5173`）。

## 操作

- 电脑：`WASD` / 方向键移动，自动锁定最近的敌人；按住 `J` 连续开火，`K` 发射副武器散射炮，`L` 朝当前移动方向闪避；开始界面按 `B` 可直接进入 BOSS 房；`P` / `Esc` 暂停。全程无需鼠标。
- 全屏：开始界面右上角的「全屏」按钮可切换浏览器全屏（手机进全屏后会自动尝试锁定横屏；不支持全屏的浏览器会隐藏该按钮）。
- 换武器：战斗中点击左侧中间的「武器」按钮，按 脉冲枪 → 冲锋枪 → 霰弹枪 → 轨道炮 循环切换，HUD 会显示当前武器。
- 手机：请横屏游玩；左下虚拟摇杆移动，右下 `FIRE` 按住连射，自动锁定屏幕内最近的敌人。`FIRE` 右上方的「副武器」发射散射炮，`FIRE` 右侧的「闪避」朝按下瞬间的移动方向冲刺。按钮尺寸随屏幕高度缩放，竖屏或小屏也不会挤出边界。开始界面点「直接挑战 BOSS」可跳过地牢单挑 BOSS。点右上角按钮暂停。竖屏时会显示横屏提示，游玩中转为竖屏会自动暂停。

## 原型内容

- Canvas 2D 游戏循环，支持键盘 / 多点触控
- 地牢楼层：每层 5 个 1000×1000 的房间直线排布 —— 起始房 → 3 个战斗房 → 传送门房
- 进入战斗房后闸门闭合，清空敌人后重新开启；三个战斗房全部清空后传送门激活，踏入即前往下一层
- 逐层下潜：敌人数量、血量与速度随楼层提升，死亡结束本局；每层和每个房间都有回血与分数奖励
- 4 种杂兵：突击者、疾行者、重甲、喷吐者
- 独立 BOSS 房：1000×1000 竞技场，单挑「压制核心」；两阶段弹幕、召唤杂兵、击破结算
- 4 种主武器：脉冲枪（均衡）、冲锋枪（高射速散布）、霰弹枪（5 发扇形）、轨道炮（慢速穿透）
- 自动瞄准、血量与受击无敌帧、连杀倍率、回血补给
- 副武器散射炮（冷却 3.4 秒）与闪避冲刺（冷却 1.6 秒，冲刺期间短暂无敌）
- 粒子、屏幕震动、命中反馈、简易合成音效
- 响应式 HUD（楼层 / 房间进度）、桌面/手机操作提示、暂停与结算界面

## 结构

```
src/
  App.tsx                 # 页面状态、输入与流程编排
  game/Game.ts            # 游戏引擎（地牢房间、遭遇、渲染）
  game/audio.ts           # WebAudio 合成音效
  components/             # HUD、触屏控制、菜单与弹窗
  styles.css              # 响应式视觉与布局
```

数值和敌人配置集中在 `src/game/Game.ts` 顶部，方便继续调参。
