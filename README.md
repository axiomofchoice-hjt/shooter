# shooter

一个用 React + Vite + TypeScript 制作的 2D 俯视角地牢射击游戏原型，桌面和手机双端适配，地牢房间为直线排布的 roguelike 楼层。

## 启动

```bash
npm install
npm run dev
```

打开终端里显示的地址（默认 `http://localhost:5173`）。

## 操作

- 电脑：`WASD` / 方向键移动，自动锁定最近的敌人；按住 `J` 连续开火，`K` 发射副武器散射炮，`L` 朝当前移动方向闪避；开始界面按 `B` 可直接进入测试房（分裂者 / 追踪者）；`P` / `Esc` 暂停。全程无需鼠标。
- 视野：镜头按「可视世界高度」统一缩放（约 660 世界像素），桌面和手机看到的地图范围基本一致，屏幕短边不会被裁掉一截；宽度不足 1000 时退化为按房间宽度取景。
- 全屏：开始界面右上角的「全屏」按钮可切换浏览器全屏（手机进全屏后会自动尝试锁定横屏；不支持全屏的浏览器会隐藏该按钮）。
- 换武器：当前开放脉冲枪、雷暴镖、聚能激光，点击左侧「武器」按钮循环切换；其余 7 把主武器已实现但暂时隐藏，无法切换到。
- 手机：请横屏游玩；左下虚拟摇杆移动，右下 `FIRE` 按住连射，自动锁定屏幕内最近的敌人。`FIRE` 右上方的「副武器」发射散射炮，`FIRE` 右侧的「闪避」朝按下瞬间的移动方向冲刺。按钮尺寸随屏幕高度缩放，竖屏或小屏也不会挤出边界。开始界面点「进入测试房」可跳过地牢，直接和分裂者、追踪者反复对练。点右上角按钮暂停。竖屏时会显示横屏提示，游玩中转为竖屏会自动暂停。

## 原型内容

- Canvas 2D 游戏循环，支持键盘 / 多点触控
- 地牢楼层：每层 5 个 1000×1000 的房间直线排布 —— 起始房 → 3 个战斗房 → 传送门房
- 进入战斗房后闸门闭合，清空敌人后重新开启；三个战斗房全部清空后传送门激活，踏入即前往下一层
- 逐层下潜：敌人数量、血量与速度随楼层提升，死亡结束本局；每层和每个房间都有回血与分数奖励
- 6 种杂兵：突击者、疾行者、重甲、喷吐者、分裂者、追踪者
- 杂兵行为循环：每轮把「1 次移动 + 1 次攻击 + 2 次静止」随机排列后依次播放，播完重新洗牌
- 移动：3~5 段慢速直线，每段在起点圆环上随机取点；80% 的概率让距离贴近该怪偏好的交战距离，20% 反向拉开
- 攻击：统一带前摇 / 判定 / 后摇——近战怪绕自身扫一圈线段，远程怪点射子弹
- 分裂者：朝开火瞬间的玩家位置抛出一颗母弹（地面会标出落点），到达落点后炸成 20 发环形子弹；分裂弹更快（430px/s）、射程无上限。母弹提前碰到玩家会立刻在原处分裂；闪避的无敌帧内母弹会直接穿过
- 追踪者：远程怪，一次连发 2 枚追踪弹；追踪弹以 255px/s 追 2.2 秒，转向速度受限（约 2.2 rad/s），锁定期结束后不再转向、只按当前朝向直线飞行
- 追踪弹碰到墙壁或玩家会炸出一小圈爆炸：直接命中 10 点伤害，贴在墙面被爆炸波及为 6 点；飞满 7 秒则无声消散，不再爆炸
- 追踪者攻击前摇会在玩家身上显示收拢的锁定框，追踪弹飞行时带虚线导引环与弯曲尾迹，丢失锁定后变灰并停止转向
- 测试房：1000×1000 竞技场，分裂者与追踪者混编；清空一波后 1.6 秒自动续波，每波 +1 只（上限 6），HUD 显示波次与剩余数量，适合反复试走位、分裂和追踪弹的锁定期
- 已实现 10 把主武器，当前开放脉冲枪、雷暴镖、聚能激光；其余 7 把（冲锋枪、霰弹枪、轨道炮、追猎炮、等离子喷火器、电弧炮、震荡炮）暂时隐藏，无法在游戏中切换，下面的数值和说明保留供恢复时参考
- 雷暴镖：1 秒/发，朝锁定敌人的原始位置掷出飞镖；0.5 秒内从快到慢移动到目标距离的 90%，然后以「目标距离 10%/秒」的低速匀速滑行（300px 目标约 30px/s）。在目标距离的 90%、95%、100%、105%、110% 处各电击一次，间隔 0.5 秒；最后一次电击后消失，总存在 2.5 秒。无接触伤害，每次以飞镖当前位置为中心、150px 范围电击所有敌人，每次 5 伤害；飞镖周围会显示一圈虚线电击范围；没有射程限制
- 聚能激光：0.75 秒/发，朝锁定方向发射一条穿透光束，命中路径上所有敌人。基础 10 伤害、光束宽 3px；攻击冷却 0.75 秒结束后才开始充能，0.75 秒充满，伤害最高 ×2（20 点）、光束最粗 32px。持续按住开火时冷却一结束就打 0 充能光束（10 伤害 / 0.75 秒）；等满充能再打是 20 伤害 / 1.5 秒，两者 DPS 都约 13.3，持续开火和满充能不再有 DPS 差距。没有弹道飞行时间，不显示射程圈；装备时角色周围会显示充能环
- 追猎炮：开火瞬间锁定射程内最近的敌人，锁定后不会换人；目标死亡时改追死亡位置，导弹飞到那里再消散。导弹以 1500px/s 飞行，从身侧带一点偏移射出，靠快速转向拉回目标（偏移只是视觉效果）；射程内没有敌人时朝正前方直射。锁定和弹道都不受墙体阻挡。
- 等离子喷火器：按住开火，向正前方约 46° 的扇形持续喷射，射程 240px；锥形范围内的所有敌人同时受到伤害，约 18 点/秒。伤害按固定 0.05 秒节拍结算，不受帧率影响；松开即停，不需要子弹命中判定
- 电弧炮：0.55 秒/发，没有最大攻击距离；命中视野内最近的敌人后，以 260px 半径跳向最近的下一个敌人，最多 4 个目标；伤害 8 → 5 → 3 → 2（每跳 ×0.62），单体约 14.5 DPS，四目标合计约 33 DPS。跳跃不受墙体阻挡，命中点会溅出电火花
- 追猎炮 / 喷火器只在 240px 内自动索敌；电弧炮、震荡炮、雷暴镖和聚能激光没有射程限制，自动瞄准视野内最近的敌人。范围外不会显示锁定框或转向
- 震荡炮：1 秒/发，炮弹以 780px/s 飞行，碰到敌人或房间墙壁立刻爆炸；150px 范围内造成 20 点伤害，并把敌人向外推开（越靠近爆心推力越大，重甲推力减半，BOSS 大幅抵抗）。冲击波只作用于敌人，玩家不受伤也不会被推；爆炸不会穿墙影响隔壁房间。没有额外射程限制，也不显示射程圈
- 装备追猎炮或等离子喷火器时，玩家周围会显示一圈较浅的虚线最大射程圈，方便判断 240px 的攻击距离
- 自动瞄准、血量与受击无敌帧（闪避期间敌方子弹、母弹、追踪弹都直接穿过，不算碰撞）、连杀倍率、回血补给
- 副武器散射炮（冷却 3.4 秒）与闪避冲刺（速度 1.82 倍移动速度，位移 158px，滑行结束后再冷却 1 秒，按钮冷却圈同样从滑行结束才开始，冲刺期间无敌）
- 闪避表现：滑行时机体过热发白，带推进尾焰、残影与拖尾光轨，起点留一圈扩散光环，一眼能和普通移动区分
- 粒子、屏幕震动、命中反馈、简易合成音效
- 响应式 HUD（楼层 / 房间进度）、桌面/手机操作提示、暂停与结算界面

## 结构

```
src/
  App.tsx                 # 页面状态、输入与流程编排
  game/Game.ts            # 游戏引擎（地牢房间、遭遇、渲染）
  game/audio.ts           # WebAudio 合成音效
  components/             # HUD、触屏控制、菜单与弹窗
  styles.css              # 响应式视觉与布局
```

数值和敌人配置集中在 `src/game/Game.ts` 顶部，方便继续调参。
