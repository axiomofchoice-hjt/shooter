# shooter

一个用 React + Vite + TypeScript 制作的 2D 俯视角射击游戏原型，桌面和手机双端适配。

## 启动

```bash
npm install
npm run dev
```

打开终端里显示的地址（默认 `http://localhost:5173`）。

## 操作

- 电脑：`WASD` / 方向键移动，鼠标瞄准，按住 `J`（或鼠标左键）连续开火；`P` / `Esc` 暂停。
- 手机：请横屏游玩；左下虚拟摇杆移动，右下 `FIRE` 按住连射，自动锁定屏幕内最近的敌人；点右上角按钮暂停。竖屏时会显示横屏提示，游玩中转为竖屏会自动暂停。

## 原型内容

- Canvas 2D 游戏循环，支持键盘 / 鼠标 / 多点触控
- 无尽波次；4 种敌人：突击者、疾行者、重甲、喷吐者
- 自动瞄准、血量与受击无敌帧、连杀倍率、回血补给
- 粒子、屏幕震动、命中反馈、简易合成音效
- 响应式 HUD、桌面/手机操作提示、暂停与结算界面

## 结构

```
src/
  App.tsx                 # 页面状态、输入与流程编排
  game/Game.ts            # 游戏引擎（更新、碰撞、波次、渲染）
  game/audio.ts           # WebAudio 合成音效
  components/             # HUD、触屏控制、菜单与弹窗
  styles.css              # 响应式视觉与布局
```

数值和敌人配置集中在 `src/game/Game.ts` 顶部，方便继续调参。
