# shooter

> 🚧 **开发中，尚不完善。**
> 这是一个还在迭代中的原型，玩法、数值、手感和界面都会随时调整；部分内容尚未开放或只是占位（例如主武器还在持续追加），进度也还没有存档。当前版本仅供试玩，不代表最终形态。

一个用 React + Vite + TypeScript 制作的 2D 俯视角地牢射击游戏原型，桌面和手机双端适配，地牢房间为直线排布的 roguelike 楼层。

## 启动

```bash
npm install
npm run dev
```

打开终端里显示的地址（默认 `http://localhost:5173`）。

## 部署

推送到 `main` 会触发 GitHub Actions（[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)）：`npm ci` → `npm run build`，然后把 `dist/` 发布到 `gh-pages` 分支。也可以在仓库的 Actions 页面手动 Run workflow。

首次使用需在仓库 Settings → Pages 里把 Source 设为 `Deploy from a branch`，分支选 `gh-pages`、目录选 `/ (root)`，之后访问 `https://<user>.github.io/shooter/`。

构建产物用相对路径（`vite.config.ts` 里的 `base: './'`），同一份 `dist` 放在域名根目录或 `/<repo>/` 子路径下都能直接打开。

## 操作

- 电脑：`WASD` / 方向键移动，自动锁定最近的敌人；按住 `J` 连续开火，`K` 发射副武器散射炮，`L` 朝移动方向闪避（松开按键时沿静止前的移动方向，从未移动则朝初始朝向；闪避途中开火仍自动索敌）；`Tab` 切换下一把主武器、`Shift+Tab` 切回上一把；开始界面按 `B` 打开测试房设置，再按 `B` / `Enter` 用当前配置开始；`P` / `Esc` 暂停。游玩全程无需鼠标。
- 视野：镜头按「可视世界高度」统一缩放（约 660 世界像素），桌面和手机看到的地图范围基本一致，屏幕短边不会被裁掉一截；宽度不足 1000 时退化为按房间宽度取景。镜头平滑跟随玩家：范围内没有敌人时，目标点在玩家前方，沿移动方向前伸（移速 × 0.4 秒，最多 140px）；范围内有敌人时，改为玩家与所有敌人重心的中点，并停用移动前伸。偏移用较慢的缓动收敛，击杀或重心变化不会让镜头瞬移；不设硬性最大速度，也不会锁在当前房间，靠近房门时能看到相邻房间，越过地图边界时还能看到地图外（例如起始房左侧）。
- 全屏：开始界面右上角的「全屏」按钮可切换浏览器全屏（手机进全屏后会自动尝试锁定横屏；不支持全屏的浏览器会隐藏该按钮）。
- 换武器：地牢按配装（`DUNGEON_LOADOUT`）携带武器，当前带脉冲枪、正交炮、连射追踪炮、抛物枪、浮游炮、协同浮游炮和浮游伙伴（后六把是临时放进配装实测的武器）。键盘 `Tab` / `Shift+Tab`、手柄 `LB` / `RB` 或点按左侧武器按钮都能切换（只勾一把时不显示按钮）。测试房设置里可以勾选任意几把（包括新枪），进入后只在勾选的武器之间切换。武器本身没有「隐藏 / 未开放」状态，不出现只代表这次没带。
- 手机：请横屏游玩；左下虚拟摇杆移动，右下 `FIRE` 按住连射，自动锁定屏幕内最近的敌人。`FIRE` 右上方的「副武器」发射散射炮，`FIRE` 右侧的「闪避」朝移动方向冲刺（停止移动后沿用静止前的方向，闪避途中开火仍自动索敌）。按钮尺寸随屏幕高度缩放，竖屏或小屏也不会挤出边界。开始界面点「进入测试房」可先勾选要用的武器和要刷的敌人，跳过地牢反复对练。点右上角按钮暂停。竖屏时会显示横屏提示，游玩中转为竖屏会自动暂停。
- 手柄：标准布局，接上即用。左摇杆 / 十字键移动，`X` 按住连射（自动索敌），`Y` 副武器，`A` 闪避，`LB` / `RB` 切换主武器（上一个 / 下一个），`Start` 暂停 / 继续；主界面 `A` / `Start` 进入地牢、`B` 打开测试房设置（设置里 `A` / `Start` 用当前配置开始、`B` 返回），暂停或结算界面 `A` / `Start` 继续 / 再战、`B` 返回主界面。

## 原型内容

- Canvas 2D 游戏循环，支持键盘 / 多点触控 / 手柄
- 地牢楼层：每层 5 个 1000×1000 的房间直线排布 —— 起始房 → 3 个战斗房 → 传送门房
- 进入战斗房后闸门闭合，清空敌人后重新开启；三个战斗房全部清空后传送门激活，踏入即前往下一层
- 房间判定以「整艘舰体穿过门洞」为准：人还在门框里时仍算前一间房，不会因为闸门在进门瞬间闭合而被挤进墙里
- 逐层下潜：敌人数量、血量与速度随楼层提升，死亡结束本局；每层和每个房间都有回血与分数奖励
- 6 种杂兵：突击者、疾行者、重甲、喷吐者、分裂者、追踪者
- 杂兵行为循环：每轮把「1 次移动 + 1 次攻击 + 2 次静止」随机排列后依次播放，播完重新洗牌
- 移动：3~5 段慢速直线，每段在起点圆环上随机取点；80% 的概率让距离贴近该怪偏好的交战距离，20% 反向拉开
- 攻击：统一带前摇 / 判定 / 后摇——近战怪绕自身扫一圈线段，远程怪点射子弹
- 分裂者：朝开火瞬间的玩家位置抛出一颗母弹（地面会标出落点），到达落点后炸成 20 发环形子弹；分裂弹更快（430px/s）、射程无上限。母弹提前碰到玩家会立刻在原处分裂；闪避的无敌帧内母弹会直接穿过
- 追踪者：远程怪，一次连发 2 枚追踪弹；追踪弹以 255px/s 追 2.2 秒，转向速度受限（约 2.2 rad/s），锁定期结束后不再转向、只按当前朝向直线飞行
- 追踪弹碰到墙壁或玩家会炸出一小圈爆炸：直接命中 10 点伤害，贴在墙面被爆炸波及为 6 点；飞满 7 秒则无声消散，不再爆炸
- 追踪者攻击前摇会在玩家身上显示收拢的锁定框，追踪弹飞行时带虚线导引环与弯曲尾迹，丢失锁定后变灰并停止转向
- 地牢起始房里有一个训练桩：无法被摧毁，也不会重置，不移动、不攻击、不给分/连杀/掉落，命中会显示伤害数字和命中特效。自动瞄准和所有武器都能锁定它，起始房的闸门与流程不受影响
- 测试房：1000×1000 竞技场，进入前可多选武器和敌人；默认勾选脉冲枪与突击者，点「进入测试房」打开设置面板。每波按勾选顺序轮换刷怪，清空一波后 1.6 秒自动续波，每波 +1 只（上限 6），HUD 显示波次与剩余数量，方便反复试走位、追踪弹锁定期和不同武器的输出
- 已实现 22 把主武器，全部都是可正常使用的主武器：地牢当前配装带脉冲枪、正交炮、连射追踪炮、抛物枪、浮游炮、协同浮游炮与浮游伙伴（后六把临时放进配装实测），测试房可任意勾选试用；下面的数值和说明对每把都适用
- 雷暴镖：1 秒/发，朝锁定敌人的原始位置掷出飞镖；0.5 秒内从快到慢移动到目标距离的 90%，然后以「目标距离 10%/秒」的低速匀速滑行（300px 目标约 30px/s）。在目标距离的 90%、95%、100%、105%、110% 处各电击一次，间隔 0.5 秒；最后一次电击后消失，总存在 2.5 秒。无接触伤害，每次以飞镖当前位置为中心、150px 范围电击所有敌人，每次 5 伤害；飞镖周围会显示一圈虚线电击范围；没有射程限制
- 聚能激光：0.75 秒/发，朝锁定方向发射一条穿透光束，命中路径上所有敌人。基础 10 伤害、光束宽 3px；攻击冷却 0.75 秒结束后才开始充能，3 秒充满，伤害最高 ×5（50 点）、光束最粗 32px。持续按住开火时冷却一结束就打 0 充能光束（10 伤害 / 0.75 秒）；等满充能再打是 50 伤害 / 3.75 秒，两者 DPS 都约 13.3。没有弹道飞行时间，不显示射程圈；充能进度改为射击口辉光，充能越高越亮越大
- 跳弹枪：0.4 秒/发（2.5 发/秒），向周围均匀的 10 个方向各射出一发（间隔 36°），其中一个方向始终对着锁定的敌人；没有目标时这个方向取移动方向。子弹 900px/s、每发 2 点伤害，命中第一个敌人即消失（不穿透）；撞到房间墙壁会反弹，最多 5 次，第 6 次撞墙时在墙面上碎裂；子弹最长存活 4.5 秒，没有额外射程限制，自动瞄准视野内最近的敌人
- 蜂巢枪：0.5 秒/发，子弹 1000px/s、5 点伤害；对同一敌人每命中 3 次或将其击杀，就在该敌人一个身位外召唤一座哨戒炮（场上最多 4 座，持续 7 秒或血量耗尽）。炮台每 0.3 秒向 280px 内最近的敌人开火，子弹 1100px/s、2.5 伤害；攻击范围用虚线圆圈标出，受伤后头顶显示血条。炮台有 40 点血量。敌人会在玩家、浮游伙伴和炮台之间选择最近的目标：只要炮台比它们更近，近战挥砍、点射、母弹和追踪弹就会改打炮台，由炮台承受伤害；换房、换层或时间到会消失
- 浮游炮：装备后 2 台浮游炮自动伴飞，不需要按开火（按了也不会从舰体开火）。它们各自挑选房间内的敌人，飞到离目标约 210px、视线无遮挡的位置（进入约 130~230px 且能看见目标时进入前摇），然后以 0.55 秒/发、4 点伤害自动射击，合计约 14.5 DPS；两台炮各自独立选择离自己最近的敌人，可能选中同一个，与玩家的索敌也完全独立，装备时不会显示玩家的索敌标记。目标再远也会一直飞到射击位，不会停在半路；目标消失或没有敌人后才回到玩家身后。移动没有惯性：直接朝目标点匀速飞，到位或悬停时立刻停住；进入 0.2 秒前摇后不会被打断，即使目标移动也固定完成并开火；开火后 0.28 秒内不移动，之后只要目标还在约 90~340px 的保持范围内就原地连续射击，只有明显跑远才重新追位，因此不会出现走一步停一下的前摇交替。没有敌人且停稳时，炮口朝向与玩家一致。子弹没有射程上限，只会在命中或飞出房间时消失。浮游炮没有血量，不会被敌人索敌，也不会被敌方子弹击中。训练桩也能自动索敌，起始房可以直接看它打桩
- 协同浮游炮：装备后 2 台浮游炮跟随在玩家附近（约 64px，左右分开），舰体不另开枪；按住或点射开火时，两台一起攻击玩家当前自动锁定的同一目标，松开后停止攻击、回到跟随。它们不会自己找目标，也不会飞向敌人；跟随位如果落在地图外或墙里，会绕玩家搜索最近的可站空位（当前房间没有内部掩体，主要处理墙边与房间外）。子弹没有射程上限，0.55 秒/发、4 点伤害，合计约 14.5 DPS；没有血量，不会被敌人索敌，也不会被敌方子弹击中；停稳且不攻击时炮口朝向与玩家一致。和原版浮游炮的区别：原版自主索敌、独立开火、不显示玩家锁定框；协同版听玩家开火指令集火同一目标，并显示玩家的锁定框
- 浮游伙伴：只有 1 台，行为和原版浮游炮一样会自己索敌、飞到目标附近、前摇/开火，但它是可被攻击的伙伴：70 点生命；敌人会在玩家、伙伴和炮台之间选最近的目标，它比玩家近时会被锁定，近战、点射、追踪弹和敌方子弹都能伤害它；被击毁后 6 秒在玩家身边重新部署。它不显示玩家的锁定框，子弹没有射程上限，0.55 秒/发、4 点伤害。和原版浮游炮的区别：原版是 2 台无敌的独立浮游炮；浮游伙伴只有 1 台、有血量、会死会复活，敌人可以攻击它
- 回收炮：没有射程上限，自动锁定视野内最近的敌人；有锁定目标时和追猎炮一样不受墙体阻挡。每次开火打出一枚 1600px/s、12 点伤害的回收弹，命中敌人后弹丸掉头飞回玩家，回到玩家身边才算回收，回收后才能打下一发；没有可锁定的敌人（或目标提前死亡）时，弹丸朝前飞到墙上再掉头返回。攻速由一整趟往返飞行时间决定，因此越近越快：0.24 秒是攻速上限（实际约 0.25 秒/发），300px 约 0.35 秒/发、600px 约 0.72 秒/发、900px 约 1.08 秒/发。中途换房 / 换枪不会卡住。装备时玩家周围有一圈小绿环，虚线表示弹丸还在飞（含回收途中）或冷却中，实线表示可以开火
- 地毯轰炸：6.5 秒/发，锁定视野内最近的敌人后，一架轰炸机从玩家身后的场外沿「玩家→目标」连线飞入，横穿整个房间后从另一侧离场；飞行约 2.4~3.3 秒，每 0.22 秒投下一颗炸弹。炸弹 0.16 秒后落地，95px 范围内 8 点伤害，并留下半径 80px 的火圈；火圈持续 3 秒，每 0.5 秒对圈内敌人造成 2.5 点伤害，场上最多保留 24 个。开火后先显示 0.55 秒的虚线轰炸走廊，飞机带地面阴影和引擎光。没有射程限制，自动瞄准视野内最近的敌人
- 裂变炮：0.6 秒/发，母弹 980px/s、10 点伤害；撞到敌人或墙壁时分裂成 10 发均匀环绕的子弹（间隔 36°），方向只由母弹的飞行方向决定，与敌人位置、墙面角度无关；小弹 720px/s、每发 1.5 伤害、存活 0.65 秒，不再分裂。母弹命中的敌人不会被同一圈小弹立刻重复命中；撞墙时朝墙内的约 5 发会直接飞进墙里消失
- 轨道球：装备时 3 颗球以 60px 半径慢速环绕玩家（离机体约一个身位），碰到敌人造成 6 点撞击伤害（同一敌人每 0.28 秒最多被撞一次），碰到敌方子弹直接将其消除；按住开火或点一下（效果维持 1 秒）时球逐渐加速并外扩到 240px（和追猎炮同射程），外扩 0.55 秒、松开后约 0.7 秒收回。待机和展开状态都能挡子弹；没有弹道，球的环绕圈就是攻击范围
- 追猎炮：开火瞬间锁定射程内最近的敌人，锁定后不会换人；目标死亡时改追死亡位置，导弹飞到那里再消散。导弹以 1500px/s 飞行，从身侧带一点偏移射出，靠快速转向拉回目标（偏移只是视觉效果）；射程内没有敌人时朝正前方直射。锁定和弹道都不受墙体阻挡。
- 等离子喷火器：按住开火，向正前方约 46° 的扇形持续喷射，射程 240px；锥形范围内的所有敌人同时受到伤害，约 18 点/秒。伤害按固定 0.05 秒节拍结算，不受帧率影响；松开即停，不需要子弹命中判定
- 电弧炮：0.55 秒/发，没有最大攻击距离；命中视野内最近的敌人后，以 260px 半径跳向最近的下一个敌人，最多 4 个目标；伤害 8 → 5 → 3 → 2（每跳 ×0.62），单体约 14.5 DPS，四目标合计约 33 DPS。跳跃不受墙体阻挡，命中点会溅出电火花
- 追猎炮 / 喷火器只在 240px 内自动索敌；电弧炮、震荡炮、雷暴镖、聚能激光、跳弹枪、裂变炮、蜂巢枪、回收炮和地毯轰炸没有射程限制，自动瞄准视野内最近的敌人；原版浮游炮同样没有射程限制，但由炮自身索敌。范围外不会显示锁定框或转向
- 震荡炮：1 秒/发，炮弹以 780px/s 飞行，碰到敌人或房间墙壁立刻爆炸；150px 范围内造成 20 点伤害，并把敌人向外推开（越靠近爆心推力越大，重甲推力减半，BOSS 大幅抵抗）。冲击波只作用于敌人，玩家不受伤也不会被推；爆炸不会穿墙影响隔壁房间。没有额外射程限制，也不显示射程圈
- 正交炮：0.06 秒/发（与冲锋枪同速），只沿上下左右四个方向之一发射冲锋枪式子弹：1200px/s、1.3 伤害、半径 3、存活 0.95 秒，不拐弯也不穿透。瞄准分三步：先选「有敌人且子弹能打到」的方向（取其中最近的敌人）；四个方向都打不到时，取最近敌人夹角最小的方向；没有敌人时取移动方向夹角最小的方向。装备时舰体朝向锁定在四个方向上，副武器散射炮也沿这个方向发射
- 连射追踪炮：0.2 秒/发，子弹与冲锋枪相同（1200px/s、1.3 伤害、半径 3、存活 0.95 秒、同样的小散布），不穿透。按住开火打出至少 3 发后松开，一次射出 3 枚追踪弹，三枚初始朝向相隔 60°、合计 120° 扇形散开；每枚在释放瞬间锁定距离最近的一个敌人（通常三枚锁同一个目标），随后转向目标、画出一道明显的弧线，直接命中 6 点，落点再造成 48px 范围 5 点小爆炸，爆炸不会重复伤害直接命中的目标。没有目标时三枚追踪弹按这个扇形直飞，寿命结束时爆炸
- 抛物枪：0.06 秒/发，子弹与冲锋枪相同（1200px/s、1.3 伤害、半径 3、0.95 秒寿命、小散布），不穿透。每命中敌人 5 次（不同敌人累计），在命中位置生成一个抛物物品：初始速度固定 300px/s，方向在背离玩家左右各约 39° 内随机；加速度固定在命中瞬间的「命中位置 → 玩家位置」方向上，大小 600px/s²。物品速度上限 300px/s，回程不会超过出手速度；存活 4.5 秒或飞出房间后消失；玩家碰到后先只播放拾取反馈，特殊效果待定
- 装备追猎炮或等离子喷火器时，玩家周围会显示一圈较浅的虚线最大射程圈，方便判断 240px 的攻击距离
- 自动瞄准、血量与受击无敌帧（闪避期间敌方子弹、母弹、追踪弹都直接穿过，不算碰撞）、连杀倍率、回血补给
- 副武器散射炮（冷却 3.4 秒）与闪避冲刺（速度 1.91 倍移动速度 / 约 515px/s，位移 170px 在 0.33 秒内滑完，滑行结束后再冷却 0.6 秒，按钮冷却圈同样从滑行结束才开始，冲刺期间无敌）；闪避方向只取移动方向——静止时沿用静止前最后的方向，从未移动则朝初始朝向，滑行中开火仍自动索敌
- 闪避表现：滑行时机体过热发白，带推进尾焰、残影与拖尾光轨，起点留一圈扩散光环，一眼能和普通移动区分
- 手柄支持（Gamepad API，标准布局）：左摇杆（带死区）/ 十字键移动，`X` 连射，`Y` 副武器，`A` 闪避，`LB` / `RB` 切上一把 / 下一把主武器，`Start` 暂停；菜单、暂停与结算界面都能纯手柄操作。手柄与键盘 / 触屏可同时使用，手柄输入优先
- 粒子、屏幕震动、命中反馈、简易合成音效
- 响应式 HUD（楼层 / 房间进度）、桌面/手机操作提示、暂停与结算界面
- 战斗 HUD 右上角实时显示帧率（0.25 秒窗口），低于 55 变黄、低于 30 变红，悬停可看每帧毫秒数

## 结构

```
src/
  App.tsx                 # 页面状态、输入与流程编排
  game/
    Game.ts               # ShooterGame 门面：画布生命周期、主循环、输入入口
    core/
      world.ts            # GameWorld：一局游戏的全部可变状态
      config.ts           # 游戏数值与视觉常量
      enemyDefs.ts        # 敌人属性、攻击与行为配置
      entities.ts         # 实体、弹道、特效等数据结构
      math.ts             # 数学与颜色工具
      testRoom.ts         # 测试房配置校验
    systems/              # 模拟系统；函数第一个参数都是 GameWorld
      world.ts            # 相机、房间几何、装饰、索敌
      player.ts           # 玩家移动、瞄准、闪避
      weapons.ts          # 主武器开火与派生弹道
      funnels.ts          # 原版浮游炮：自主索敌、走位与前摇
      coopFunnels.ts      # 协同浮游炮：跟随、玩家目标集火
      partner.ts          # 浮游伙伴：可被攻击的自主伙伴
      weaponItems.ts      # 抛物物品、雷暴镖、轰炸机、回收弹
      combat.ts           # 子弹、冲击波与敌方弹道结算
      enemies.ts          # 敌人 AI、移动与攻击
      enemyProjectiles.ts # 敌方炮弹、追踪弹与爆炸
      turrets.ts          # 蜂巢炮台
      damage.ts           # 伤害、受击与死亡结算
      rooms.ts            # 地牢房间、遭遇、传送门与测试房
      spawn.ts            # 刷怪与训练桩
      pickups.ts          # 掉落与拾取
      boss.ts             # Boss 血条与结算
      fx.ts               # 粒子、飘字与短时特效
      hud.ts              # HUD 快照
      input.ts            # 输入归一化与清空
      loop.ts             # 每帧更新调度
      session.ts          # 开局与回主菜单
    render/               # 只读渲染层，按场景 / 实体 / 弹道 / 特效拆分
      render.ts           # 渲染调度
      scene.ts            # 地板、墙、门、房间标签
      props.ts            # 传送门、拾取物、射程圈、轰炸阴影、火圈
      enemies.ts          # 敌人本体、攻击预警与血条
      player.ts           # 玩家舰体、闪避尾焰与残影
      turrets.ts          # 炮台与轨道球
      projectiles.ts      # 各类子弹、导弹与冲击波
      funnels.ts          # 浮游炮机体、牵引线与枪口闪光
      weapons.ts          # 武器表现、轰炸机与状态环
      fx.ts               # 粒子、飘字、锁定框、屏幕效果
      overlay.ts          # 横幅与菜单氛围
      shared.ts           # 缓存光晕与房间配色
    weapons.ts            # 武器数值表
    audio.ts              # WebAudio 合成音效
    gamepad.ts            # Gamepad API 轮询与标准按钮映射
  components/             # HUD、触屏控制、菜单与弹窗
  styles.css              # 响应式视觉与布局
```

数值和敌人配置集中在 `src/game/core/config.ts` 与 `src/game/core/enemyDefs.ts`，方便继续调参。模拟与渲染都通过 `GameWorld` 读写状态；新增玩法按依赖方向放进 `systems/`，新增画面放进 `render/`，`Game.ts` 只保留门面。
